# Software Requirements Specification (SRS)
## Ether Arena - 2D Fighting Game

### 1. Introduction
**1.1 Purpose**  
This document specifies the requirements for Ether Arena, a 2-player 2D fighting game.

**1.2 Scope**  
Ether Arena is a fast-paced 2D fighting game with pixel-art characters, special moves, health bars, and arena backgrounds.

**1.3 Definitions**  
- Player 1 / Player 2: Human-controlled fighters
- Ether: Energy used for special attacks

### 2. Overall Description
**2.1 Product Perspective**  
Standalone browser-based HTML5 Canvas game.

**2.2 Functional Requirements**
- Two playable characters with distinct colors/styles
- Movement, jumping, basic attacks, and special attacks
- Health system and win conditions
- Particle effects and visual feedback
- Keyboard controls for both players
- Restart functionality

**2.3 Non-Functional Requirements**
- Smooth 60 FPS gameplay
- Responsive keyboard controls
- Royalty-free assets only

### 3. System Features
- Character sprites (idle, attack, jump)
- Arena background
- Health bars and UI
- Special attack system
- Sound effects (optional)
